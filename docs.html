Documentation

Welcome to the JSON Generator documentation. This guide will help you understand how to use all the features of our tool to create complex JSON structures with random data.

Getting Started

Basic Concepts

The JSON Generator allows you to define a schema for your JSON data, which is then used to generate random data that matches your specifications. Here are the key concepts:

  • Fields: The basic building blocks of your JSON structure. Each field has a name and a type.
  • Types: Each field can be one of several types: string, number, boolean, array, object, or array of objects.
  • Constraints: For each type, you can define constraints like possible values, ranges, probabilities, etc.
  • Nesting: You can create complex structures by nesting objects and arrays within each other.

Field Types

String Fields

String fields generate text values. You can provide a list of possible values, and the generator will randomly select one for each generated entry.

Example: String Field

{
  "name": "John Smith"  // Randomly selected from your list of names
}

Number Fields

Number fields generate numeric values. You can specify a minimum and maximum value, as well as the number of decimal places.

Example: Number Field

{
  "price": 149.99  // Random number between your min and max values
}

Boolean Fields

Boolean fields generate true/false values. You can set the probability of generating a true value.

Example: Boolean Field

{
  "inStock": true  // Based on your specified probability
}

Array Fields

Array fields generate lists of values. You can specify the possible values and the minimum and maximum number of items in the array.

Example: Array Field

{
  "tags": ["premium", "wireless", "audio"]  // Random selection from your values
}

Object Fields

Object fields generate nested objects. You can add child fields to objects to create complex structures.

Example: Object Field

{
  "address": {
    "street": "123 Main St",
    "city": "Boston",
    "zipCode": "02108"
  }
}

Array of Objects

This special type generates an array containing multiple objects with the same structure. You can specify the minimum and maximum number of objects in the array.

Example: Array of Objects

{
  "phoneNumbers": [
    {
      "type": "home",
      "number": "555-1234"
    },
    {
      "type": "work",
      "number": "555-5678"
    }
  ]
}

Advanced Features

Generating Multiple Entries

You can generate multiple JSON entries at once by setting the "Total JSON Entries" value. This is useful when you need a collection of similar but randomly varied data.

Exporting Your Data

Once you've generated your JSON data, you can download it as a .json file for use in your applications. Simply click the "Download JSON" button after generating your data.
